## 当前基线摘要

### 目标
- Web 端跑通“手动选择素材 -> 预览优化 -> 风格选择 -> 生成 -> 下载/分享”的完整闭环。
- App 端支持“相册授权 -> 智能筛选/手动选择 -> 预览优化 -> 风格选择 -> 生成 -> 写回相册/分享”的完整闭环。
- 统一产品心智：素材选取 + 预览优化 + 风格化生成 + 输出。

### Web 范围边界
- 仅支持用户手动选择/上传图片与视频。
- 不支持全库相册访问、后台索引、人物识别、系统相册写回。
- 智能筛选入口仅用于提示下载 App。
- 视频生成优先浏览器侧完成，不可用环境降级到服务端生成或提示使用 App。

### App 范围边界
- 支持相册权限、全库与增量读取、智能筛选、人物识别、稳定视频生成和写回系统相册。
